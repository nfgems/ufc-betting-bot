## 1. Executive assessment

The production model is genuinely strong where most hobby systems are weak — leak-disciplined 202-feature contract with fail-closed validation, mirror-augmented training with symmetric inference, native-NaN honesty, and an honest temporal eval (+8.2% ROI, 61.5% WR, +2.36% CLV on 247 bets 2022+) already at open-source SOTA — so the headroom is not in exotic features or architectures. It splits into three buckets, in descending certainty: **(a) correctness gaps between what was validated and what runs live** — the `opp_strength` family is fed a semantically different quantity on 96.3% of 2025+ predictions, the snapshot fallback serves one-fight-stale rows, and exact-name lookups silently NaN the pre-UFC family (~12% of booster gain share); **(b) mechanical training waste** — the served booster never trains on the newest 1,293 fights (2024-02 → 2026-05), which carry **79.7% of the time-decay weight mass**, even though a full-data booster is already fit every run and discarded (`src/model/train.py:714`); **(c) a systematically optimistic evaluation/selection layer** — frictionless fills with instant settlement feeding both config selection and the promotion trading bar, backtest entry at T-7 opening prices while live executes inside 48h, best-of-2,916 config selection on the reporting window, point-estimate promotion on ROI whose 95% CI is roughly ±15pp at n=247, and a stage-4 control freeze that is currently **non-functional** (v5 metrics only, no trading artifacts — all stage-4 trading verdicts are blocked today). Fixing (c) doesn't add ROI directly, but it determines which of the (a)/(b)/feature candidates actually get promoted, so it compounds across every future cycle.

#### E7. Statistically honest promotion gate — priority 75
- **Why:** Trading bar passes on raw `c_roi > b_roi` at n≈247 where the ROI 95% CI is ~±15pp (`promotion_gate.py:418-438`); the only bootstrap is unpaired and i.i.d. per bet (`lab_stats.py:156-159`); CLV is contaminated — **82.6% of matched fights are single-snapshot**, structurally computing CLV=0, and realistic-mode CLV mixes fill-incl-spread vs fair bases (`backtest.py:935-939`); stage 4 compares against a months-stale frozen window. A properly paired bootstrap already exists (`src/model/compare.py:45-114`) but is wired only into the xgboost-vs-no-odds report.
- **Experiment:** Paired **event-clustered** bootstrap of candidate-minus-baseline P&L (absent arm = 0; fight-key pairing only for CLV/model-bar); CLV-primary criterion (`clv_fair`, NaN not 0 for non-distinct snapshots, min distinct-n ≥ 80); permutation false-promote test (expect old gate ~50% → new ~5%); seed-twin test (a reseeded v6 clone must not promote); recompute the headline CLV with the distinctness filter (n drops to ~150 of 247 — the +2.36% figure will shift). Note `logs/evaluation/` is empty locally, so stage 1-3 must be regenerated for the historical v5-vs-v6 re-check.
- **Winner:** Lower false-promote rate at equal true-promote sensitivity on experiments (a)-(c); becomes default stage-4 path with `--legacy-gate` fallback.

#### E8. Kill sweep selection bias: forward-chained config selection + reserved window — priority 71
- **Why:** Configs are picked as best-of-2,916 on the same window that produces the reported numbers (`duo_trader_sweep.py:616-681`); the "holdout" fold is *included* in selection data and advisory only (`run_evaluation.py:1742-1770`); stage 4 then compares best-of-grid vs a single frozen control config — structural pro-candidate bias. The fixed 2022-01-01 bet-start has been reused across every cycle (`config.py:211`), and production strategy constants sit at the grid centers.
- **Experiment:** Config-by-fold stats matrix (additive — bankroll resets per `_evaluate_config` call); for k ≥ 4 select best on folds 1..k-1, score on fold k; compare out-of-fold ROI vs in-sample best-config ROI, plus a block-bootstrap selection-noise null. Zero-code sensitivity run: `bet_start_date='2024-01-01'` via existing kwargs. If gap > ~3pp: reserve the last 2 folds (~12 months) from selection, score the chosen config once on the reserve, and feed *that* row to stage 4 (symmetrically for the control config); record window-usage in run metadata.
- **Winner:** Diagnostic first (the OOF-vs-in-sample gap is the result); process fix promotes only reserve-window numbers thereafter. Note the headline +8.2% is the production *anchor* config, not best-of-sweep, so this mainly corrects candidate selection, not the headline.

#### E9. Fitted logit-space stacking of model and market probabilities — priority 70
- **Why:** The blend uses five hand-set, never-fit constants (`value.py:130-174`, `config.py:214-228`), and `dynamic_blend_weight` reads module globals so 4 of 5 are **unsweepable today** (sweeps only tune base weight; dead imports at `model_variants.py:22-25` confirm). It is also anti-shrinkage: up-weights the model at extreme probs where tree overconfidence is worst. The post-blend probability — the number actually compared to the 2% edge threshold and fed to Kelly — is never calibration-measured.
- **Experiment:** Phase 1 (~30 lines): parameterize the four constants through SweepConfig + a static-weight ablation. Phase 2: per-fold `LogisticRegression` on [logit(p_model), logit(p_market)] (+logit(p_noodds) where present, never imputed), fit on prior folds only using pre-2022 data (5,436 odds-covered fights available via `generate_variant_fold_predictions(bet_start_date="2016-01-01")`), fit on mirrored pairs to force b0≈0 (A/B symmetry), keep pair renormalization; jointly re-sweep `s_min_edge` {0.015-0.03}.
- **Winner:** Blend-prob Brier/ECE beat heuristic on 2022+ folds AND bet count doesn't drop >50% without ROI/CLV compensation; kill if fitted b1 ≈ 0.

#### E10. Promote opponent-allowed (defensive vulnerability) rolling stats — priority 64
- **Why:** The pipeline already rolls opp_ versions of every stat (`build_features.py:227-228`; `a_roll_opp_td_landed` 89.9% non-null 2014+) but the contract consumes only 2 derivatives. Live needs **zero new code** for a_/b_ values (already EWM-rolled at `fighter_lookup.py:1859-1862` and prefixed wholesale at :2372-2375) — only 4 entries in each diff list. Collinearity with existing defense features is modest (max |r|=0.39); univariate r for ctrl_seconds-conceded (-0.063) and sub-attempts-faced (-0.049) is in the same band as features that made the v6 cut.

#### E11. Calibration ablation (weighted sigmoid / isotonic / temperature / beta) + blend instrumentation — priority 58
- **Why:** The temporal-holdout calibrator fit silently **drops time-decay sample weights** (`train.py:693-698` — the timeseries and group-cv paths pass them), so 2024 fights weigh equal to 2026 in the probability mapping despite the recency-weighted booster; weights span 5-8x inside the cal window at hl=365, so the fix is not a no-op. `calibration_method="temperature"` works today with zero code (sklearn 1.8 passes it through); beta needs a ~50-line wrapper. The blended probability driving bets is never Brier/ECE-measured anywhere (`model_lab.py:559` scores raw prob_a only).
- **Experiment:** Phase 0 first and free: emit `blend_brier`/`blend_ece` (esp. the 0.40-0.65 band where the 2% threshold creates/destroys bets) in `run_variant_walkforward` — this measures the **current production config** before any retraining. Then arms: weighted-sigmoid (1-2 lines/call site), isotonic, temperature, beta, none — same holdout, after E6.
- **Winner:** Banded blend-ECE primary; model bar via `promotion_gate`. Expect small effect sizes; do not select on ROI at n≈247. Defer the post-blend calibrator (double-dips market info).

#### E12. Antithetic, mirror-consistent odds noise — priority 59
- **Why:** Noise is drawn independently per column over all 9 odds features including diff (`train.py:526-567`), so training rows violate a+b=1 (sum deviation std ≈ 0.085) and diff=a−b (≈0.104) — identities every live row satisfies exactly (`odds_client.py:251-254`, `bot.py:2374-2378`). The model trains off the manifold it predicts on. Found in verification: noise is applied **after** mirror augmentation, so mirrored twins get independent noise, breaking the exact symmetry the May 2026 remediation established. Seed 42 is frozen (MAJ-05) — a deterministic shift, not regularization. The safeguard is kept and strengthened, never removed.
- **Experiment:** `odds_noise_mode` spec/variant field; one eps per mirror group, a+=eps/b−=eps (sign-flipped on the mirrored row), recompute diff, skip NaN rows; keep independent draws on the 6 method-odds columns (no live identity exists). Arms: independent-0.06 (baseline), antithetic-0.06, antithetic std {0.03, 0.045, 0.09}, antithetic-empirical (close-vs-open deltas, measured std 0.043). 5-seed dispersion band on baseline and best arm (recorded seeds — keeps the reproducible-spec convention).
- **Winner:** ECE/Brier improve and ROI/CLV non-inferior **across seeds**; declare neutral if the lift sits inside the seed-dispersion band (which itself quantifies MAJ-05). Final validation through the production train path (`train_all_models`), not the lab trainer.
